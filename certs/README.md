# Сертификат для T-Invest API

`russian-trusted-root-ca.crt` — публичный **Russian Trusted Root CA**, сертификат НУЦ Минцифры РФ (RSA). Он используется только отдельным `ssl.SSLContext` клиента в `tbank.py`. Системные хранилища сервера и контейнера, стандартные TLS-контексты Python и настройки других сервисов не изменяются. Проверки цепочки и имени сервера остаются обязательными. Перенаправления к другим доменам отключены.

Источник: [официальная инструкция Т-Банка](https://status.tbank-online.com/certificates/), раздел Linux, ссылка на [корневой RSA-сертификат](https://help-static2.tbank-online.com/certs/linux_russian_trusted_root_ca_pem/russian_trusted_root_ca_pem.crt). Загружен 2026-10-31 по HTTPS с включённой стандартной проверкой TLS; проверены подпись корня, признак CA и срок действия.

- Subject / Issuer: `CN=Russian Trusted Root CA,O=The Ministry of Digital Development and Communications,C=RU`
- Действует до: `2032-02-27T21:04:15Z`
- SHA-256 отпечаток сертификата (DER): `d26d2d0231b7c39f92cc738512ba54103519e4405d68b5bd703e9788ca8ecf31`

Промежуточные сертификаты API передаёт при TLS-рукопожатии. В доверенные корни добавлен только указанный RSA-корень; сертификаты GOST не требуются для проверенного RSA-соединения. Публичный сертификат не содержит закрытого ключа или API-токена и хранится в Git и образе приложения.

Для другого явно выбранного оператором PEM-набора задайте `INVEST_TBANK_CA_FILE`. Настройка действует только на клиент Т-Инвестиций. При обновлении сертификата проверяйте HTTPS-источник банка, срок действия, CA-признак и отпечаток; после замены пересоберите образ.
